# drive_book_voice_service_api

DriveBookVoiceServiceApi - JavaScript client for drive_book_voice_service_api
API for AI voice agent to interact with DriveBook platform for booking driving lessons.
The hybrid voice service exposes these `/api/_*` endpoints and proxies them to the main DriveBook application.

RECOMMENDED AI CONVERSATION FLOW (OPTIMIZED):
1. Ask user for pickup location
2. Validate location via /locations/validate
3. Get smart recommendations via /instructors/recommendations (AI-ranked, top 3)
4. Present options: \"I found 3 great instructors: Debesay (top rated), Michael (best value), Sarah (closest)\"
5. User selects instructor
6. Call /availability/slots to check times
7. Call /packages to present package options with savings
8. Create booking via /public/bookings/bulk (backend calculates pricing, generates password)

KEY IMPROVEMENTS:
- AI does NOT ask for password (backend generates secure password automatically)
