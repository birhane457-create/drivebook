## Batch 1 — From initial audit (subscription, analytics, expenses, clients/[id], pda-configs)

### 🔴 C-1 — `subscription/page.tsx`: Billing history dates use no locale or timezone
**Lines:** `currentPeriodStart`, `currentPeriodEnd` in billing history section  
**Code:**
```ts
new Date(currentSubscription.currentPeriodStart).toLocaleDateString()
new Date(currentSubscription.currentPeriodEnd).toLocaleDateString()
```
**Problem:** No `en-AU` locale, no `timeZone`. Will render in server locale (US format M/D/YYYY in some environments). An instructor whose subscription renews Aug 1 could see Jul 31.  
**Fix:**
```ts
new Date(currentSubscription.currentPeriodStart).toLocaleDateString('en-AU', { day: 'numeric', month: 'long', year: 'numeric' })
```
**Status:** Open

---

### 🔴 C-2 — `analytics/page.tsx`: API error is completely silent — page hangs forever
**Lines:** `fetchAnalytics`  
**Code:**
```ts
const res = await fetch(`/api/analytics?period=${period}`)
if (res.ok) { const data = await res.json(); setAnalytics(data) }
// if !res.ok: setAnalytics never called, loading = false, analytics = null
// Result: page renders "Loading analytics..." forever
```
**Problem:** A 401 (session expiry), 500 (server error), or 404 means the instructor sees a perpetual spinner with no feedback.  
**Fix:** Add `else { setError('Failed to load analytics') }` and render an error state.  
**Status:** FIXED 2026-08-06

### 🟠 H-1 — `expenses/page.tsx`: Settings fetch is sequential before data fetches
**Lines:** `loadData`  
**Code:**
```ts
const settingsRes = await fetch('/api/instructor/settings');  // blocks
// THEN:
const [expRes, earningsRes] = await Promise.all([...])
```
**Problem:** Settings fetch blocks the parallel expenses+earnings fetch. Adds ~200–400ms to every page load (and every filter change).  
**Fix:** Include settings in the `Promise.all`:
```ts
const [settingsRes, expRes, earningsRes] = await Promise.all([
  fetch('/api/instructor/settings'),
  fetch(`/api/instructor/expenses?${params}`),
  fetch(`/api/instructor/earnings?${params}`),
])
```
**Status:** Open

---

**Line:** Active plan status box  
**Code:**
```ts
Renews on {new Date(currentSubscription.currentPeriodEnd).toLocaleDateString()}
```

**Problem:** No locale → system default → US format in some environments (M/D/YYYY).  
**Fix:** `toLocaleDateString('en-AU', { day: 'numeric', month: 'long', year: 'numeric' })`

### 🟠 H-3 — `clients/[id]/page.tsx`: Booking history dates use browser timezone
