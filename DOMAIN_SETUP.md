## DNS Configuration

### Primary Domain: drivebook.com.au

**Vercel Deployment:**
```
A Record:
  Host: @
  Points to: 76.76.21.21 (Vercel)

CNAME Record:
  Host: www
  Points to: cname.vercel-dns.com
```

**API Endpoints:**
- Main App: `https://drivebook.com.au`
- API Base: `https://drivebook.com.au/api`
- Webhooks: `https://drivebook.com.au/api/webhooks`

### Secondary Domain: drivebook.au

**Setup as Redirect:**
```
301 Redirect:
  drivebook.au → drivebook.com.au
  www.drivebook.au → drivebook.com.au
```

**Why Redirect:**
- SEO: Consolidates domain authority to .com.au
- Branding: Single primary domain
- User Experience: Works with both domains

## Vercel Configuration

### 1. Add Domains to Vercel

```bash
# In Vercel Dashboard:
# Settings → Domains → Add Domain

# Add both:
drivebook.com.au (Primary)
drivebook.au (Redirect)
```

### 2. Configure Redirects

**vercel.json:**
```json
{
  "redirects": [
    {
      "source": "/:path*",
      "has": [
        {
          "type": "host",
          "value": "drivebook.au"
        }
      ],
      "destination": "https://drivebook.com.au/:path*",
      "permanent": true
    },
    {
      "source": "/:path*",
      "has": [
        {
          "type": "host",
          "value": "www.drivebook.au"
        }
      ],
      "destination": "https://drivebook.com.au/:path*",
      "permanent": true
    }
  ]
}
```
