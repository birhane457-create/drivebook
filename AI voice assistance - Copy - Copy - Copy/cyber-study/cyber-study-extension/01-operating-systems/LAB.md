# Lab — Operating Systems

## Environment
Use a local Linux VM/container and, if available, an authorized Windows VM.

## Tasks
1. Create two non-production users and one group.
2. Create a test file with deliberately different owner/group permissions.
3. Demonstrate which identity can read, modify and execute it.
4. List running processes and identify their owners.
5. Identify active services and their startup configuration.
6. Locate recent authentication/system events.
7. Use Bash to filter a log for failed authentication events.
8. Use PowerShell to query Windows Security/System events, if Windows is available.
9. Document three hardening controls.

## Required observations
Record commands, timestamps, expected result and actual result. Do not include passwords, tokens or secrets.

## Deliverable
Complete `EVIDENCE.md` with command output excerpts or screenshots where useful.
