# Lab — Networking

## Tasks
1. Build a small isolated lab network.
2. Calculate the subnet and usable address range for three example CIDRs.
3. Observe DHCP assignment or document a static configuration.
4. Inspect ARP behavior on the lab network.
5. Capture your own HTTP request to a local test service.
6. Capture a TLS connection to an authorized endpoint and identify handshake metadata without decrypting protected content.
7. Use Wireshark or tcpdump to filter DNS, TCP and TLS traffic.
8. Identify one normal connection and document its five-tuple.
9. Create a simple network diagram showing DriveBook trust boundaries.
10. Explain where segmentation or monitoring could reduce risk.

## Deliverable
Complete `EVIDENCE.md`. Do not upload credentials, cookies, authorization headers or private traffic.
