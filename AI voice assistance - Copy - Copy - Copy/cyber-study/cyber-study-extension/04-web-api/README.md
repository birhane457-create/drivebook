# 04 — Advanced Web & API Security

## Objective
Extend OWASP fundamentals into authorization, business logic, race conditions, SSRF, file handling and webhook/payment security.

## Learning outcomes
- Test object and function authorization safely.
- Reason about race conditions and state transitions.
- Analyze business-logic abuse.
- Explain SSRF, path traversal and file-upload risks.
- Understand CORS/CSP/security headers.
- Review API rate limits and abuse controls.
- Analyze webhook authenticity, replay and idempotency.
- Apply secure coding and verification discipline.

## Sequence
1. BOLA/IDOR
2. Broken function-level authorization
3. Privilege escalation
4. Business logic
5. Race conditions
6. SSRF/path traversal/file upload
7. CORS/CSP/headers
8. API abuse/rate limits
9. Webhooks/replay/idempotency
10. Payment security
11. Secure code review

## Safety
Use local/staging targets and synthetic data. Do not probe third-party services or production payment flows.
