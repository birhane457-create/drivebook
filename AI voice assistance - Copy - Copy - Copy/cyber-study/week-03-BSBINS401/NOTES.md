# Week 3 — BSBINS401: Analyse and Present Research Information

## What this unit is about

Research methodology and reporting:
- How to find and evaluate information sources
- How to analyse data and identify patterns
- How to write a structured report
- Referencing and avoiding plagiarism
- Presenting findings to different audiences

This is the most "academic" unit. The good news: for cyber security, your research will be about real threats and technologies — interesting material.

---

## Key Concepts

### 1. Research Process
1. **Define the question** — what exactly are you trying to find out?
2. **Identify sources** — where will you look?
3. **Evaluate sources** — is this reliable? Current? Relevant?
4. **Analyse** — what patterns, contradictions, or conclusions emerge?
5. **Synthesise** — combine findings into a coherent position
6. **Present** — write it up for your audience

### 2. Evaluating Sources — CRAAP Test

| Criterion | Question to ask |
|-----------|----------------|
| **C**urrency | Is it recent enough? (cyber threats change fast — anything over 3 years is suspect) |
| **R**elevance | Does it answer your question? Is it written for your level? |
| **A**uthority | Who wrote it? Are they qualified? Is it peer-reviewed? |
| **A**ccuracy | Are claims supported by evidence? Are sources cited? |
| **P**urpose | Is the author trying to inform or sell something? |

Good sources for cyber research:
- **ACSC** (Australian Cyber Security Centre) — acsc.gov.au — authoritative for Australian context
- **NIST** — nist.gov — US standards body, globally respected
- **OWASP** — owasp.org — web application security best practice
- **CVE database** — cve.mitre.org — known vulnerability records
- **Vendor security advisories** — e.g., GitHub Security Advisories, Microsoft Security Bulletins

Avoid: random blog posts without author credentials, content older than 3 years for threat data, vendor marketing disguised as research

### 3. Report Structure

```
Title
Executive Summary (1 page max — what you found and what to do about it)
Introduction (background, scope, research question)
Methodology (how you researched — what sources, how you evaluated them)
Findings (what you found — facts, data, quotes with references)
Analysis (what the findings mean — patterns, implications)
Recommendations (what should be done)
Conclusion
References (APA or Harvard format)
Appendices (raw data, screenshots, code excerpts)
```

### 4. Referencing (APA 7th edition — most common in Australian TAFE)

Website:
> Author, A. A. (Year, Month Day). *Title of page*. Site Name. URL

Example:
> Australian Cyber Security Centre. (2024, October 15). *Annual cyber threat report 2024*. Australian Government. https://www.cyber.gov.au

## Practice Task

Write a 500-word research report on ONE of these topics:
1. The most common web application vulnerabilities affecting Australian businesses in the past 12 months
2. How the Australian Privacy Act 1988 (amended) affects how a SaaS business must handle user data breaches

Use at least 3 sources. Apply the CRAAP test to each source before using it.
