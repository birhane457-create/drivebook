# 02 — Networking & Traffic Analysis

## Objective
Move from protocol theory to practical network investigation.

## Learning outcomes
- Explain ARP, DHCP, NAT, routing, subnetting, VLANs and ports.
- Distinguish packets, connections, sockets and application requests.
- Capture and inspect authorized traffic with Wireshark/tcpdump.
- Investigate DNS and HTTP behavior.
- Explain TLS at a protocol level without exposing secrets.
- Recognize indicators of scanning, flooding and suspicious traffic.
- Map network controls to DriveBook.

## Sequence
1. IPv4/subnets
2. ARP/DHCP/NAT
3. Routing/VLANs
4. TCP/UDP and sockets
5. DNS investigation
6. HTTP traffic analysis
7. TLS inspection concepts
8. Wireshark/tcpdump
9. IDS/IPS, segmentation and proxies

## Safety
Capture only your own lab traffic or traffic explicitly authorized for analysis.
