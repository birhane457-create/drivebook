# Lab — Advanced Web/API

## Tasks
1. Build a toy API with two synthetic users and object ownership.
2. Demonstrate an insecure object lookup in the toy app.
3. Add server-side authorization and verify the cross-user request is denied.
4. Create a controlled concurrent update test and identify the race window.
5. Add an atomic constraint/transaction and rerun the test.
6. Review a toy file-upload endpoint for path traversal and type-validation issues.
7. Review a toy outbound URL feature for SSRF controls.
8. Test CORS behavior using only your local test origin.
9. Design a webhook with signature verification, event validation, replay protection and idempotency.
10. Map each control to an existing DriveBook security boundary.

## Required evidence
Capture expected vs observed results and state-change behavior. Never use live payment credentials or real customer data.
