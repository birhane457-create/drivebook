# 01 — Operating Systems & Host Security

## Objective
Build practical understanding of Linux and Windows hosts as security boundaries.

## Learning outcomes
- Explain users, groups, permissions and privilege.
- Inspect processes, services, filesystems and environment variables.
- Locate and interpret authentication and system logs.
- Use Bash and PowerShell for safe investigation.
- Distinguish normal administration from security investigation.
- Map host controls to DriveBook deployment/runtime components.

## Sequence
1. Linux filesystem, users/groups and permissions
2. Processes, services and scheduled tasks
3. Linux authentication and logs
4. Windows accounts, services and Event Logs
5. Bash investigation
6. PowerShell investigation
7. Host hardening and least privilege
8. DriveBook runtime mapping

## Completion gate
Do not mark complete until the lab and evidence record are populated and the learner can orally explain the observations and limitations.

## Safety
Use a local VM/container or other explicitly authorized environment. Do not alter production hosts.
